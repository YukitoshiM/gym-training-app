# BodyMode Support

[日本語]({{ '/support/' | relative_url }})

For a problem or feedback about a TestFlight build, use **Send Beta Feedback** in the TestFlight app.

The following information helps us investigate a problem:

- The screen where it occurred
- The action immediately before it occurred
- Whether it happens every time
- Your iPhone and Apple Watch models and OS versions
- Your BodyMode version and build number
- A diagnostic report exported from BodyMode Settings

For support or bug reports about the public release, use [BodyMode GitHub Issues](https://github.com/YukitoshiM/gym-training-app/issues/new). Do not include health information, photos, API keys, your name, address, or other personal information in a public issue. If a diagnostic report is needed, first post only a general description of the problem.
