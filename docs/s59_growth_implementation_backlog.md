## 運用ルール

- 状態は`未着手 / 設計済み / 実装中 / 実装済み / 実機確認済み`のいずれかにする。
- 実装済みはビルドと自動テストが通った状態を指す。
- 実機確認が必要な項目は、完了日と検証端末を記録する。
- 各項目の要件変更はこの台帳と`ai_coach_social_monetization_design.md`を同じ変更で更新する。
- HealthKit由来データを広告・スポンサー・一般分析イベントへ追加しない。
