# BodyMode グローバル配信・多言語化計画

> 本書は設計時の詳細計画です。現在の完了・残件は`production_launch_remaining_tasks.md`を正本とします。

更新日: 2026-08-24

## 1. 決定

BodyModeは、初回正式版からEU27を除く148の国・地域を同時に対象とする。日本先行や英語圏先行などの段階配信は行わない。EUは個人開発者のDSA公開連絡先リスクを避けるため保留し、専用の事業者連絡先を維持できる収益段階で追加を再検討する。

配信地域と対応言語は分けて扱う。今回の公開ローカリゼーションは日本語1件と翻訳先43件とし、保留した6言語の地域では当面英語へフォールバックする。

App Store ConnectではEU27を明示的に配信不可とし、それ以外の148地域を有効にする。各国の法令、AppleまたはGoogleの制限、制裁、年齢・健康・広告要件により追加対応が必要になった地域は随時見直す。

公開前に当たる市場を決め打ちしない。公開後は国・言語別のインストール、オンボーディング完了、D1/D7/D30継続率、DailyAction完了率、AI成功率、広告表示率、eCPMを比較し、反応の強い市場からストア素材、翻訳品質、サポート、集客を重点改善する。

AdMobの広告ユニット自体に国別配信設定は設けない。アプリの配信地域、広告需要、AdMob審査、各地域の同意状態に応じて配信される。

## 2. 現状

- iPhone、Watch、Widget、Info.plistへString Catalogを導入し、44ロケールを接続済み。
- 構造QAはiPhone 2,163キー、Watch 236キー、Widget 2キーで明示欠落0。
- 日本語以外の未対応法務本文は英語へフォールバックする。
- App Store商品ページと公開法務・サポートページは日本語・英語を用意済み。主要市場の健康・法務・課金表現は人手確認を残す。
- 英国、スイスとEU外EEA向けAdMob同意メッセージを設定済み。EU配信再開時にも再利用する。

## 着手タイミング

多言語実装は完了し、App Store ConnectのEU27を除く148地域を有効化済み。DSAは非トレーダー・EU配信予定なしとして有効化済み。残る作業は主要市場の重点レビューと、正式候補Buildでの表示・VoiceOver確認である。

## 3. 公開ゲート

対象148地域を公開する前に、次を完了する。

### G0: アプリ基盤

- String Catalogを導入し、ユーザー表示文字列をSwiftコードから分離する。
- 日本語を原文、英語を共通フォールバックとし、今回の43対象ローカリゼーションを主要画面、エラー、通知、Watch、Widgetで提供する。
- 複数形、語順、文字幅、VoiceOver読み上げをローカライズ可能にする。
- 日付、時刻、数値、小数点、週の開始日を`Locale`で表示する。
- 身長、腹囲、距離、重量はメートル法とヤード・ポンド法を選択できるようにする。
- AIへ利用言語と単位系を渡し、回答言語と単位を統一する。

### G1: ストア・法務

- 今回公開する44ローカリゼーションについて、App Store名、説明、キーワード、スクリーンショットを用意する。
- プライバシーポリシー、利用規約、サポートページを同じ言語範囲で公開する。
- App Privacy、年齢、健康・医療表現、輸出、DSA等を配信地域に合わせて回答する。
- グローバル利用者を受け付けるサポート方針と返信目標を決める。

### G2: 広告・同意

- EEA、英国、スイス向けUMPメッセージを維持する。
- 米国州規制向けメッセージを作成し、対象地域だけへ表示する。
- 非パーソナライズ、追跡なし、健康データを広告選定に使わない方針を維持する。
- 公開後にApp Store掲載情報をAdMobへリンクし、アプリ審査を完了する。

### G3: 運用

- AIサーバーの海外からの到達性、応答時間、レート制限、障害時表示を確認する。
- 英語でAIチャット、食事写真、体型写真、週次提案を受入テストする。
- 国別のインストール、継続率、広告表示率、eCPM、AI成功率を確認する。

## 4. 対応言語

正式公開時は、次の44ローカリゼーションを対象にする。今回対象外の言語とAppleが直接対応しない現地語は英語へフォールバックする。

- アラビア語、カタロニア語、中国語（簡体字・繁体字）
- クロアチア語、チェコ語、デンマーク語、オランダ語
- 英語（オーストラリア・カナダ・英国・米国）
- フィンランド語、フランス語、フランス語（カナダ）、ドイツ語、ギリシャ語
- グジャラート語、ヘブライ語、ヒンディー語、ハンガリー語、インドネシア語、イタリア語、日本語
- 韓国語、マレー語、マラーティー語、ノルウェー語
- ポーランド語、ポルトガル語（ブラジル・ポルトガル）、ルーマニア語、ロシア語
- スロバキア語、スロベニア語、スペイン語（メキシコ・スペイン）、スウェーデン語
- タミル語、テルグ語、タイ語、トルコ語、ウクライナ語、ベトナム語

今回の保留対象は、ベンガル語、カンナダ語、マラヤーラム語、オディア語、パンジャブ語、ウルドゥー語。自動翻訳の文字体系・意味品質が公開基準に届かなかったためであり、対象言語話者のレビューと実機QAを用意できた時点で追加を再検討する。

翻訳は生成AIによる一括生成を基本とし、用語集、プレースホルダー、文字数、未翻訳キー、画面崩れを自動検査する。健康上の注意、AIの安全表現、プライバシーポリシー、利用規約、同意画面は逆翻訳と重点レビューを必須にする。

Appleが対応言語を変更した場合は、正式公開前に公式一覧を再取得して対象を更新する。

## 5. 実装順

1. 文字列抽出とString Catalog導入
2. 共通用語集、翻訳ルール、英語フォールバックの確定
3. 生成AIで43対象ローカリゼーションを一括生成
4. 単位・日付・数値の地域対応
5. 未翻訳、プレースホルダー、文字幅、主要フローを自動検査
6. Watch、Widget、通知、AI回答言語を全対象言語へ対応
7. 法務ページ、同意画面、ストア素材を全対象言語へ対応
8. 健康・安全・法務表現を重点レビュー
9. 米国州規制メッセージ
10. 初回正式版のApp Store Connect設定でEU27を除く148地域を一斉に有効化
11. AdMob審査後に国別収益を監視
