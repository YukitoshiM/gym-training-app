# BodyMode 翻訳依頼テンプレート

以下を翻訳用チャットへ貼り、`TARGET_LOCALE`を`target_locales.csv`で`translation_strategy`が`source`または`deferred`ではない値へ置き換え、JSONLを1ファイルだけ添付する。

```text
BodyModeという健康・ボディメイク管理アプリの翻訳をしてください。

対象ロケール: TARGET_LOCALE
原文: 日本語
入力: 添付したJSONL 1ファイル

要件:
1. 全行を入力順のまま翻訳し、省略・追加・結合しない。
2. 出力も1行1JSONのJSONLにする。
3. 各行は {"id":"入力と同じID","target_locale":"TARGET_LOCALE","translation":"翻訳文","review_note":""} とする。
4. {{value1}}、{{value2}}、%1$@、%@、%dなどのプレースホルダーは文字も個数も変更しない。
5. BodyMode、Apple Watch、Apple Health、HealthKit、RPE、PFC、kcal、kg、lb、bpmは文脈に応じて正式・一般的な表記を使う。
6. 大人向けの健康アプリとして、短く、信頼でき、責めない表現にする。診断・治療・効果保証に見える表現を追加しない。
7. ボタン、タブ、Watch表示は特に短くする。直訳より、その地域のフィットネスアプリで自然な用語を優先する。
8. 重量、回数、セット、休憩、テンポ、疲労、食事、栄養、体型写真などはロケール内で用語を統一する。
9. 原文の意味が曖昧、文化的に不自然、または画面幅に収まりにくい場合だけreview_noteへ日本語で理由を書く。
10. JSONL以外の説明、Markdown、コードフェンスは出力しない。
```

## 法務・ストア文書用

Markdown文書を翻訳する場合は次を追加する。

```text
見出し構造、箇条書き、URL、メールアドレス、免責の意味を維持してください。法的意味を勝手に拡張・縮小せず、解釈に不安がある箇所へ <!-- REVIEW: 理由 --> を付けてください。App Storeの名前とサブタイトルは各30文字以内を守り、キーワードは対象市場の検索語として自然にしてください。
```
