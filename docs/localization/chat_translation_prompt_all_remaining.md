# BodyMode 残り全パック一括翻訳依頼

添付した日本語原文JSONLを、`target_locales.csv`にある全対象言語へ翻訳してください。

## 入力

- `translation_source_ja_remaining_all_11_packs.jsonl`
- `target_locales.csv`
- `translation_remaining_11_packs_manifest.json`

日本語原文は1,887件、今回の対象ロケールは日本語と`deferred`を除く43件です。

## 成果物

- ファイル名: `translation_remaining_all_11_packs_all_43_locales.jsonl`
- 期待行数: 81,141行（1,887件 × 43言語）
- 会話本文へ全件を貼らず、ダウンロード可能なUTF-8 JSONLファイルとして作成する

## 出力形式

各行は次の4項目だけを持つ1行1JSONとします。

```json
{"id":"入力と同じID","target_locale":"対象ロケール","translation":"翻訳文","review_note":""}
```

## 必須条件

1. ロケール順は`target_locales.csv`の順とし、`translation_strategy`が`source`または`deferred`のロケールは除外する。
2. 各ロケール内は日本語原文JSONLの入力順を維持する。
3. すべての原文を各ロケールへ1回ずつ翻訳し、省略・追加・結合・分割しない。
4. `id`は一字も変更しない。
5. `{{value1}}`、`{{value2}}`、`%1$@`、`%@`、`%d`などのプレースホルダーは文字・個数を変更しない。
6. BodyModeは変更しない。Apple Watch、Apple Health、HealthKit、RPE、PFC、kcal、kg、lb、bpmは対象地域で一般的な表記を使う。
7. 大人向け健康アプリとして、短く、自然で、信頼でき、責めない表現にする。
8. 診断、治療、効果保証、恐怖をあおる表現を追加しない。
9. ボタン、タブ、Apple Watchの表示は特に短くする。
10. 重量、回数、セット、休憩、テンポ、疲労、食事、栄養、体型写真、身体測定の用語をロケール内で統一する。
11. 意味が曖昧、文化的に不自然、文法的に成立しにくい断片、画面幅に収まりにくい文だけ、`review_note`へ日本語で理由を書く。
12. RTL言語へ方向制御文字を追加しない。
13. 英語・フランス語・スペイン語・ポルトガル語の地域差は同梱CSVの`translation_strategy`に従う。

## 完了前の機械検査

次をすべて検査し、エラーが0件になるまで成果物を確定しないでください。

- 43ロケールが存在する
- 各ロケールが1,887件である
- 合計81,141行である
- IDの欠落・追加・重複がない
- 各ロケール内のID順が原文と一致する
- 翻訳の空欄がない
- プレースホルダーの欠落・追加・重複がない
- JSONL以外の説明やコードフェンスが混入していない

処理量が多い場合は内部的にロケール単位で分割・再開して構いません。ただし、最終成果物は必ず上記ファイル1つに統合してください。
