# BodyModeデータ取り込み

## 対応形式

| 形式 | 判定 | 取り込む内容 |
| --- | --- | --- |
| BodyMode JSON | `schemaVersion` | 全バックアップ。現在データを置換 |
| Strong CSV | `Date`, `Workout Name`, `Exercise Name`, `Set Order` | ワークアウト、種目、セット |
| Hevy CSV | `title`, `start_time`, `exercise_title`, `set_index` | ワークアウト、種目、セット |
| JEFIT CSV | ファイル名とJEFIT固有列 | ワークアウト、種目、セット |
| 一般CSV | 日時・種目・重量・回数の別名列 | ワークアウト、種目、セット |
| Apple Health XML | `HealthData`と`Record`/`Workout` | 体重、腹囲、体脂肪率、ワークアウト概要 |

CSVはUTF-8 BOM、CRLF、引用符内改行、余分な列、0/1始まりのセット番号を許容する。列順には依存しない。

## 安全性

- 重量列に単位がない場合、kg/lbを選ぶまで取り込めない。
- 日時にタイムゾーンがない場合、端末タイムゾーンを明示確認するまで取り込めない。
- 未登録種目は元の名称を保ったカスタム種目として追加する。
- 外部履歴には計画値がないため、セットを`isAdded`として保存し、過去の計画達成率へ含めない。
- SHA-256ファイルfingerprintと、日時・種目・セット内容の意味的キーで再取り込みを防ぐ。
- 適用前に全対象データを保護領域へ保存し、直前の取り込みを一括で元に戻せる。
- BodyMode復元はスキーマ7を現行とし、スキーマ6を読み込める。8以上は新しいアプリが必要として拒否する。

## プレビュー

設定の「データ」→「記録を取り込む」からファイルを選択する。形式、追加件数、重複除外数、警告、必要な単位・タイムゾーン確認を表示してから適用する。BodyMode JSONだけは現在データの置換を明示確認する。

## テストデータ

`GymTrainingAppTests/Fixtures/DataImport`に、公開されている各エクスポート列仕様を再現した匿名化ファイルfixtureを置く。テストは文字列を直接組み立てず、実際のCSV、XML、JSONファイルを読み込む。
