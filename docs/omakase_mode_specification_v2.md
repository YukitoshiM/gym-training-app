# BodyMode おまかせモード仕様書 v2

更新日: 2026-08-12  
状態: 実装済み・次回配布ビルド対象

## 1. プロダクト原則

BodyModeは、自分の身体について今日何をすればよいかを決めてくれるアプリとする。

ユーザーの中心体験は次の循環である。

1. 開く
2. 今日の3つを見る
3. やる
4. 記録が反映される
5. BodyModeが傾向を学ぶ
6. 明日の3つが良くなる

既存の記録、分析、AI、トレーニング機能は削除しない。既存機能を判断材料と実行先にし、ホームでは今日必要な情報だけを見せる。

## 2. 中心ユーザーストーリー

### US-01 朝

ユーザーはアプリを開くだけで、今日の調子と今日やることを確認できる。

処理順:

1. 端末内ルールで即時判断する
2. 今日の調子を表示する
3. 今日やることを最大3件表示する
4. AIが利用可能ならバックグラウンドで追加分析する
5. 重要な差がある場合だけ提案を補正する

AI未接続、通信失敗、HealthKit未許可でもホーム表示と手動記録は成立させる。

### US-02 記録

入力負担を次の優先順位で減らす。

1. HealthKitなどから自動取得
2. 写真
3. ワンタップ
4. 手入力

体重は毎日、体型写真と腹囲は原則週1回を提案する。疲労感は必要時、食事は食事時に記録する。目的と既存記録によって提案頻度を変える。

### US-03 食事

食事写真または食べたものリストをAI解析し、料理名、量、カロリー、PFCの下書きを作る。ユーザーが確認・修正して保存すると、今日の進捗へ反映する。

カロリーは成功・失敗の二値判定に使わない。DailyActionの完了には、タンパク質量または食事記録回数を使用する。

### US-04 運動

ホームの最優先アクションから、その日に必要な実行先へ直接移動する。

- トレーニング日: 選択済み計画をiPhoneまたはWatchで開始
- 休養日: 歩数または回復状態を確認
- 記録日: 体重、腹囲、体型写真、食事を直接記録

固定のトレーニング開始ボタンにはしない。マシンの空き状況による種目順変更は失敗扱いにしない。

### US-05 夜

完了数と各アクションの状態を短く表示する。未達成を責めず、完了・未完了・ユーザーが外した項目を翌日の判断材料にする。

## 3. ホーム情報設計

表示順は固定する。

1. 今日の調子
2. 今日やること最大3件
3. 最優先アクションの大きな実行ボタン
4. クイック記録: 食事、体重、写真
5. 今日の達成度
6. 詳しく見る

グラフ、PR、詳細PFC、履歴、詳細分析は「詳しく見る」以下または各専用タブに置く。

各アクションは、実行、理由表示、別行動への入れ替えを提供する。完了済みアクションは入れ替えない。

## 4. 今日の調子

表示レベル:

- `GOOD`
- `NORMAL`
- `TIRED`
- `REST`

内部では次を保持する。

```swift
DailyReadiness {
    level
    confidence
    contributingFactors
    missingData
}
```

ホームにはレベルだけを大きく表示する。「なぜ？」では判断要因、欠測項目、データ充足度を表示する。医療診断表現は使用しない。

## 5. DailyAction

アクション候補:

- トレーニング
- 歩数・軽負荷活動
- タンパク質
- 食事記録
- 体重
- 腹囲
- 体型写真
- 睡眠
- 回復

全ての自動生成アクションに機械判定可能な完了条件を設定する。

| アクション | 完了条件 |
|---|---|
| トレーニング | 対象計画またはいずれかのセッションが完了 |
| 歩数 | HealthKit歩数が目標以上 |
| タンパク質 | 当日の食事P合計が目標の90%以上 |
| 食事 | 当日の食事記録数が目標以上 |
| 体重・腹囲 | 当日の対象BodyMetricが存在 |
| 体型写真 | 当日の写真付き撮影セットが存在 |
| 睡眠 | 昨夜の睡眠時間が目標以上 |
| 回復 | 夜20時以降まで完了ワークアウトがない |

## 6. ローカル即時判断

`Local Recommendation Engine`は次を入力にする。

- 当日の選択済み計画
- 既存トレーニング計画
- 前回および今週の完了トレーニング
- HealthKitスナップショット
- 当日の食事、身体、写真、疲労記録
- 目的、週回数、1回の時間、栄養目標
- 過去の提案完了・スキップ傾向

朝に決めた3件は日中の小さなデータ変化では入れ替えない。記録追加時は進捗と完了状態だけを同期する。強い疲労など安全側への大きな変化、ユーザーの計画選択、計画・プロフィール変更では再生成できる。

## 7. AI補正

ローカル提案表示後、既存のAI Context Builderを利用して短期、4週間、長期傾向を含む点検リクエストをバックグラウンド送信する。

AI補正を反映する条件:

- AIが変更理由を返している
- 最大3件の有効な提案として解析できる
- 調子を安全側へ変更する、またはアクションカテゴリが変わる
- 完了済みアクションを維持できる

小さな文言差ではアクションを変更しない。通信失敗や不正JSONではローカル提案を維持する。

提案の変更は`RecommendationRevision`として、変更前、変更後、理由、変更元を保存する。変更元は`localRule`、`ai`、`user`とする。

## 8. 「なぜ？」

各アクションは短い根拠を持つ。理由画面では次を表示する。

- 提案理由
- 今日の調子を判断した要因
- 不足データ
- 最新の提案変更理由

理由画面から担当AIコーチへ移動し、その提案について相談できる。

## 8.1 担当トレーナー

コーチの専門分野とトレーナーの外見・人格を分離する。ユーザーは6目的それぞれの女性・男性、合計12人から、理想の身体と相性に近い担当コーチを選択できる。

- 専門分野: 減量、筋肥大、筋力向上、ボディメイク、健康維持、復帰
- 担当トレーナー: Aiko、Leo、Maya、Noor、Diego、Priya

アバターは広告用のスタジオ写真ではなく、ランニング後のベランダ、ジムのロッカー、公園、地域のコート、自宅のキッチン、スタジオの入口など、日常の中で友人がスマートフォンで撮影したような写真とする。背景、服装、撮影角度、年齢・人種・ジェンダー表現を多様にし、自然な親近感と健康的な魅力を両立する。

選択したトレーナーの名前、アバター、話し方はホーム、AIハブ、チャット、計画作成・修正、週次レポート、提案理由、食事分析、体型写真分析、記憶確認、参照データ確認、AIコンテキストへ反映する。専門分野によって外見を固定しない。

AIの通信状態や法的注意など、人格ではなくシステム状態を伝える場所にはアバターを置かない。担当トレーナーの助言・分析・会話であることを示す場所に限定し、機能ごとに別人格に見えないよう統一する。

## 9. 重要な目標変更

摂取カロリー目標など重要な設定は自動確定しない。

直近14日を前半・後半の週平均へ分け、目的別の体重変化しきい値を超えた場合だけ、100kcal単位の調整候補を表示する。ユーザーが承認した場合だけプロフィールへ反映し、却下も保存する。同じ提案は7日以内に再表示しない。

## 10. Watch

Watchは実行端末とする。

- 今日の調子
- 最大3アクションと完了数
- 推奨トレーニングの開始
- 種目、重量、回数、セット完了、休憩タイマー

分析や複雑な設定はiPhoneへ寄せる。トレーニング計画がない休養日でも、今日の内容だけをWatchへ同期して表示できる。

## 11. 初回体験

必須の質問を次の4項目にまとめる。

1. 何を目指す？
2. 週何回運動できる？
3. 利用できる器具は？
4. 現在の身体情報

経験、1回の時間、担当コーチは週回数画面へまとめ、身体情報は任意入力とする。詳細な目標像、重点部位、性別、単位などは設定から変更できる。

完了時は「毎日、今日やることを最大3つ提案する」ことを案内し、既存の操作チュートリアルへ続ける。

## 12. 通知

通知は初期オフで、ユーザー許可後のみ使用する。朝は今日の最優先アクション、夜は残りの行動または振り返りを通知する。通知はアプリ起動要求ではなく、具体的な行動を短く伝える。

## 13. 保存とデータ保持

次を保護されたローカルストレージへ保存する。

- `DailyRecommendation`: 90日
- `DailyReview`: 90日
- `RecommendationRevision`: 最大200件
- `TargetAdjustmentProposal`: 最大50件

全データ書き出しと削除の対象に含める。データ書き出しスキーマは`4`とする。

## 14. 分析指標

North Star:

`1つ以上DailyActionを完了した日 / アクティブ日`

明示同意制の匿名利用分析には、日次提案生成、日次提案変更、カテゴリ別DailyAction完了を追加する。端末と運営サーバーで最大90日保持し、健康値、自由記述、写真、AI本文は収集しない。

補助指標:

- D1 / D7 / D30
- 3件完了率
- トレーニング実行率
- 食事写真記録率
- AI提案からの行動率
- 平均入力操作数
- AI提案変更率
