# BodyMode AIコーチ 12人キャスト案

更新日: 2026-08-14
状態: **アプリ反映済み。TestFlight Build 17で外部配布中**

## 1. 方針

6つの目的ごとに女性1人・男性1人、合計12人を用意する。

ユーザーは、次の2点で担当を選ぶ。

1. 自分が目指したい身体や生活に近いか
2. この人物なら相談を続けられそうか

同じ目的の2人はAIが参照する専門領域と安全境界を共有する。違うのは、人物、理想体型の見せ方、話し方、励まし方である。性別、人種、年齢、体格を能力や医学的信頼性の根拠にはしない。

## 2. 共通ビジュアル

- 半写実の手描きアニメーション
- 自然な成人の骨格・体格・年齢表現
- ジムだけでなく、キッチン、屋外、地域施設など日常の場面を使う
- 正面の宣材写真ではなく、ユーザーへ働きかけている瞬間を描く
- 深緑、ネイビー、コーラルを中心にし、背景の生活色を残す
- 極端な絞り、性的なポーズ、競技前の身体、白衣、資格章を使わない
- 小さい顔アイコンと大きな全身カードの両方で識別できる構図にする

## 4. 選択UX

初回設定で12人を一度に横並びにしない。

1. ユーザーが目的を選ぶ
2. その目的の2人を大きなカードで表示する
3. カードには全身画像、名前、理想像、話し方、一言を表示する
4. 「この人に任せる」で選択する
5. 「ほかの目的のコーチを見る」から全12人へ移動できる

設定画面では目的タブで6組を切り替える。写真だけで判断させず、VoiceOverと文字拡大でも理想像と話し方が分かるようにする。

## 5. AIへの反映

- `coach_id`は既存の6種類を維持する
- 同じ目的の男女ペアは専門性、参照記録、安全境界を共有する
- Personaごとに受け止め方、説明の長さ、励まし方、第一声を変える
- 根拠、数値、医療境界はキャラクターによって変えない
- 架空の資格、指導年数、競技実績を作らない
- ユーザーが人物を変更しても、記録とAI記憶は失わない

## 6. 実装前確認

- 12人の名前、年齢、背景、体格が区別できる
- 同じ目的の2人に性格上の選択理由がある
- 性別や体格を能力の根拠として表示していない
- 画像を円形に切り抜いても人物を識別できる
- 目的変更時に担当変更を勝手に確定しない
- 既存6人からのデータ移行規則を決めてから`CoachPersona`を変更する
