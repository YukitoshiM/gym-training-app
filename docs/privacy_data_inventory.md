# BodyMode データ取扱一覧

更新日: 2026-08-23

この表をプライバシーポリシー、App Store ConnectのApp Privacy回答、権限説明、AI共有設定の照合元とする。外部SDKまたは送信先を追加する前に更新する。

## 2. 利用分析へ入れる情報

固定イベント名、イベントUUID、日時、アプリバージョン、言語、固定された画面・身体記録種別、目的、経験、今日の調子、提案カテゴリ、表示位置、提案元、完了方法、差替え理由だけを保存する。自由記述は受け付けず、サーバーでも許可値以外を拒否する。サーバーではD1/D7/D30と削除対象を判別するため、認証済みインストールIDから作る復元不能なHMACキーを利用する。アカウントID、氏名、メール、広告IDとは結合しない。

利用分析へ入れないもの:

- 身体・栄養・運動・センサーの数値
- 写真、位置、種目名、食事名、メモなどの内容
- 生年、性別、APIキー、AI接続URL、AI入出力
- 広告ID、メールアドレス、端末固有ID

## 3. 外部通信

初回版はiPhone本体にGoogle Mobile Ads SDKとUMP SDKを入れる。広告SDKは同意情報の更新後にだけ起動し、健康・身体・食事・写真・運動・睡眠・位置の値を広告リクエストへ入れない。外部分析SDKと追加のクラッシュ収集SDKは入れない。明示同意時の粗い利用イベントと、ユーザーが実行したAI処理だけがBodyMode管理のCloudflare Workerへ送られる。iPhoneとApple Watchの同期はWatchConnectivityを使う。

本番AIリクエストはCloudflare Workersを経由してOpenAI Responses APIへ送る。`store: false`を指定し、BodyModeのD1と運用ログへ入力文、AI回答、写真、身体・健康値を保存しない。D1に保存するのは仮名アカウント、クレジット・購入台帳、ランダムなrequest ID、機能、モデル、処理結果、トークン数、処理時間、エラー分類などの運用メタデータである。OpenAIはAPI入出力を既定で学習に使用しないが、不正利用監視ログに入力、出力、画像が含まれ、通常最大30日保持される場合がある。この委託先保持をAppleのApp Privacy上の収集へ含める。

## 4. App Store Connect回答前の確認

- 最終Releaseビルドの通信をPrivacy Reportで確認する。
- App Privacyでは、OpenAIが不正利用監視ログを通常最大30日保持し得るため、AIへ送る健康、フィットネス、写真、その他のユーザーコンテンツを「収集」に含める。
- HealthKit、写真、位置、モーションの用途説明が実際の使用項目と一致していることを確認する。
- Privacy ManifestのRequired Reason APIと、追加する全SDKのmanifest/signatureを確認する。
- Google Mobile Ads SDKの最新データ開示とRelease ArchiveのPrivacy Reportを照合し、概算位置、識別子、広告データ、操作、診断、パフォーマンスをApp Privacyへ正確に申告する。
- Health & Fitnessカテゴリの規制対象医療機器に関する申告を回答する。本アプリは医療機器を標榜しない。
- 広告または外部分析を追加した時は、この表、同意画面、プライバシーポリシー、App Privacyを同じリリースで更新する。

## 5. ローカル保護方針

- iPhone内の記録はApplication Supportの専用フォルダへ保存し、初回ロック解除後に利用できるファイル保護を適用する。Watch同期やバックグラウンド処理を妨げない保護レベルとする。
- 記録フォルダと診断フォルダは端末バックアップの対象外とする。必要な記録はユーザーがJSONで書き出す。
- 旧版のUserDefaults保存値は初回読込時に保護ファイルへ移行し、移行成功後に旧値を削除する。
- 診断ログは最大14日、1,000件、2MiBで自動整理し、設定から即時削除できる。

## 6. 公開前に再確認する項目

- 最終Release ArchiveのPrivacy ReportとApp Store Connectの13データ種類を照合する。
- AdMobのDevice IDをTrackingありとする現在の保守的申告が、First-party ID無効・ATT非使用・非パーソナライズ広告の最終Archiveと整合するか確認する。
- OpenAIまたはGoogleのデータ取扱い、SDK、保持方針を変更した場合は同じリリースで本台帳、公開ポリシー、App Privacyを更新する。
