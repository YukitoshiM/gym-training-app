# カロリー推定テスト結果

## テスト画像

生成条件:

- 白米 150g
- 鶏むね肉（皮なし）120g
- ブロッコリー 80g
- ゆで卵 1個

一般的な食品成分値から求めた参考カロリーは約540 kcalです。生成画像なので、これは実測値ではありません。

## API結果

| 項目 | 結果 |
|---|---:|
| HTTP | 200 |
| 推定カロリー | 483 kcal |
| 参考値との差 | -57 kcal |
| 誤差率 | 10.5% |
| タンパク質 | 45 g |
| 脂質 | 22 g |
| 炭水化物 | 90 g |
| 信頼度 | medium |
| 初回応答時間 | 73.1秒 |

## 判定

カロリーは参考値から100 kcal以内となり、MVPの自動入力値としては合格です。

料理構成はおおむね認識できましたが、卵1個を2個分、白米150gを200gと推定しました。この結果からも、推定後に量と栄養値を手動補正できる現在の設計が必要です。

応答時間の大部分は料理名・PFCを生成する補助モデルによるものです。CalorieCLIP単体の推論とは分けて、今後短縮を検討します。

## アプリ接続テスト

iPhone 17 Simulatorの写真ライブラリへテスト画像を登録し、次の操作をUIテストで実行しました。

1. アプリの「記録」から「食事」を開く
2. 「食事を追加」を開く
3. 写真ライブラリからテスト画像を選ぶ
4. Mac mini上のAPIへ画像をアップロードする
5. 料理名と483 kcalが自動入力されることを確認する

結果: **成功（XCUITest 1件、失敗0件）**

実行時間は32.0秒でした。結果画面は `app-upload-result.png` に保存しています。
